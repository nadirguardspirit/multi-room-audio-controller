## 🛠 Feature Breakdown

### Feature 1 — Home Assistant Core
Install HA on a Raspberry Pi, NUC, or Docker host and add every speaker as a media player.

### Feature 2 — AmpVortex Routing
Route any source to any zone, with priority rules, ducking, and fallback chains.

### Feature 3 — HOLOWHAS Sync
Millisecond-accurate playback across rooms, even over Wi-Fi.

### Feature 4 — Multi-Zone Scenes
Party mode, Focus mode, Night mode — one tap to reconfigure the whole house.

### Feature 5 — Voice Control
Integrate with Alexa, Google Assistant, or HA Voice for hands-free operation.

### Feature 6 — Hardware Flexibility
Works with Sonos, Chromecast, Snapcast, AirPlay, DLNA, and DIY Pi DACs.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Audio delay between rooms** | Enable HOLOWHAS |
| **Speakers drop out** | Wired network |
| **Wrong zone playing** | Check AmpVortex priority |
| **HA integration fails** | Update integration |
| **Sync drift over time** | Enable periodic re-sync |
| **Codec mismatch** | Force PCM / FLAC |
